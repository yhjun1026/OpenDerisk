# Overview

OpenDerisk is an AI-Native **Multi-Agent development and runtime framework**. It lets you build, debug, and run collaborating agents that turn a single query into a delivered result — with the full achievement path visible to humans. Our vision is to provide every production system with a 7×24 AI teammate that handles complex tasks and safeguards system stability.

## What you can do

- **Build agents** — Compose prompts, context resources, models, skills/MCP, knowledge, and memory in a three-pane editor with live debug preview.
- **Run agents in a Workspace** — A scenario space centered on value delivery, showing the achievement path (planning → execution → result) with tasks, artifacts, deliveries, playbooks, and triggers.
- **Trust your data** — The ECP semantic layer makes text2SQL and data analysis trustworthy: AI proposes, humans confirm, and numbers only come from confirmed metrics.
- **Use built-in scenarios** — AI-SRE (OpenRCA root-cause diagnosis), DataExpert, and Flame Graph Assistant, ready to use and open to extend.

## Architecture at a glance

OpenDerisk is organized into five layers: Interaction & Product, Agent Runtime (`ReActMasterAgent` + pluggable reasoning engines), Capabilities (Tools/Skills/MCP/Knowledge/Memory/Media), Data & Integration (Datasources/ECP/Channels/Sandbox), and Foundation (Models/Storage/Permissions/Audit). See the [main README](../../README.md) for the full diagram.
